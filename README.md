# RecallFlow (リコールフロー)

**忘却曲線（間隔反復 / SuperMemo SM-2）アルゴリズムを搭載した、白と青の爽やかなデスクトップ暗記アプリ**

---

## 🎨 改良アップデート内容

1. **カード反転モード（通常モードとは別で忘却曲線を独立保存）**
   - **通常モード（表→裏）** と **反転モード（裏→表）** の2つの学習スタイルに対応。
   - 英単語なら「英→日」と「日→英」で難易度や定着スピードが異なるため、**それぞれ独立した間隔反復（SM-2）パラメータ（復習間隔、難易度係数、次回復習日）を別々に記録・保存**します。
   - デッキカード上で「表→裏で学習」と「裏→表 (反転) で学習」をワンクリックで選べ、それぞれの今日復習すべき枚数が個別のバッジで確認できます。
   - 忘却曲線・統計ダッシュボードやカード一覧でも、通常と反転をタブで切り替えて定着度を個別に分析可能です。

2. **白基調＋青アクセントの清潔感デザイン**
   - 背景は柔らかな白と淡いライトグレー（#f8fafc）、アクセントカラーに鮮やかなロイヤルブルー（#2563eb）を採用。
   - 視認性が高く、長時間の学習でも目が疲れにくい爽やかでクリーンなUIです。

3. **1回20問固定セッション ＆ 継続/終了の選択方式**
   - 「もう一度」を繰り返し選んだ場合でも無限ループに陥らないよう、**1セッションは最大20問（20回回答）で確実に一区切り**となります。
   - 20問解き終えた時点で「リザルト＆休憩画面」が表示され、次の20問を続けるか、終了して休憩するかを選べます。

4. **キーボードショートカット（ASDF対応）**
   - <kbd>Space</kbd> / <kbd>Enter</kbd> : 答えを表示
   - <kbd>A</kbd> : もう一度 (Again)
   - <kbd>S</kbd> : 難しい (Hard)
   - <kbd>D</kbd> : 普通 (Good)
   - <kbd>F</kbd> : 簡単 (Easy)
   - <kbd>R</kbd> : 音声読み上げ (TTS)

5. **スマートなデッキ操作（三点リーダーメニュー）**
   - デッキタイトルの横にある「︙」ボタンから、デッキ名の編集や削除を簡単に行えます。

## 🧠 特長と機能

- **SM-2 忘却曲線アルゴリズム**: 定着度に合わせて「もう一度」「難しい」「普通」「簡単」の4段階評価。各ボタンに次回出題予定日数がリアルタイム表示。
- **キーボード完全対応**: <kbd>Space</kbd>/<kbd>Enter</kbd>（答え表示）、<kbd>1</kbd>〜<kbd>4</kbd>（評価）、<kbd>R</kbd>（音声読み上げ）。
- **音声自動読み上げ (TTS)**: 英語の単語・例文の発音を自動再生。
- **デッキ＆カード管理**: 自由なカード追加、編集、削除、検索、タグ付け。
- **CSV / JSON バックアップ**: スプレッドシートからのCSVインポートやワンクリックデータ保存。
- **統計ダッシュボード**: 成熟カード数、今後7日間の復習予測グラフ、連続学習ストリーク。
